# RFC Index

Design discussion logs for pcl-rustic, sorted by ID. RFCs are append-only:
new findings are appended, never rewritten. File naming:

```
rfc-{NNNN}-{kebab-title}-{YYYY-MM-DD}.md
```

`NNNN` is a zero-padded sequence issued in order and never reused; the date is
the draft date.

The record set was reset on 2026-08-22 as part of the full-structure
redesign; pre-redesign records live in git history only.
